# Employee-Data-Analysis-Hands-On
An Excel-based employee data analysis project exploring salary distribution, employee performance, departmental insights, bonus eligibility and promotion opportunities.

## Project Overview
This project analyses employee data to explore salary distribution, workforce demographics, employee performance and departmental characteristics using Microsoft Excel.

## Project Objectives
- Analyse employee salaries across departments.
- Examine employee performance and experience.
- Identify bonus and promotion eligibility.
- Explore employee tax categories.

## Tools Used
- Microsoft Excel

## Key Areas of Analysis
- Employee demographics
- Salary distribution
- Departmental analysis
- Performance ratings
- Bonus and promotion eligibility
- Tax categorisation

## Conclusion
The project demonstrates how data analytics can support workforce analysis and provide insights into employee compensation, performance and organisational structure.
